# The patches rebased onto Newton 1.7.0

Each of the record's patch families in its latest form, rebased onto Newton 1.7.0 as released on PyPI, for the seventh
registered study ([`PREREGISTRATION_07.md`](../../preregistrations/PREREGISTRATION_07.md)). Each changes Newton only
when its switch is set, as on 1.6.1; the switches and their values are the 1.6.1 patches' own (see
[the patches](../../docs/patches.md)). Checksums in [`SHA256SUMS`](SHA256SUMS).
