# The runs

Every run of this record, design probes included, in order. Each folder under [`validation/`](../validation/) holds
the script that played it, the raw files and a README with the reading. A design probe finds where to look and
decides nothing; a study decides. Probe scripts that state a prediction were pushed before their plays.
